# 📝 To-Do Web App

A simple To-Do web application built using HTML, CSS, and JavaScript.

## 🚀 Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Simple and user-friendly interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## ▶️ How to Run

1. Download or clone the project
2. Open `index.html` in your browser
